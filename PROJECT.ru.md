Актуальная проверенная матрица функций: [FEATURES.md](FEATURES.md). Результаты аудита: [AUDIT.md](AUDIT.md). Приоритеты и оценка: [ROADMAP.md](ROADMAP.md).

## Что это за приложение

**Focus Break** — бесплатное приложение с открытым исходным кодом для планирования небольших задач, сосредоточенной работы и регулярных перерывов за компьютером или телефоном.

Главный сценарий: выбрать дело, включить таймер, спокойно поработать, сделать перерыв и увидеть результат за день. Задачи, заметки и статистика объединяются в одном приложении.

Проект предназначен для самостоятельного использования: студентами, разработчиками, людьми на удалённой работе и всеми, кому удобно работать короткими сессиями. Пользователь сам выбирает длительность работы и отдыха.

## Текущее состояние

Есть рабочая первая версия с браузерным интерфейсом. Она проходила 13 тестов логики и 8 браузерных сценариев.

Сейчас ведётся переработка во вторую версию — устанавливаемое приложение для ПК и Android с расширенным планированием задач.

**Windows Setup и файл без установки собраны локально, но не прошли нативную приёмку. APK не собран.** Расширенные задачи и планировщик проверены в браузере; это не подтверждает нативную работу Windows или Android. Публичного GitHub Release нет. Отправка в remote и публикация требуют отдельного разрешения владельца.

Файл MIT уже присутствует с предыдущего этапа. По новому ТЗ окончательный выбор лицензии остаётся за владельцем; в рамках аудита он не финализирован.

## Функции рабочей первой версии

### 1. Таймер работы и перерывов

- Режим фокуса: по умолчанию 25 минут.
- Короткий перерыв: по умолчанию 5 минут.
- Длинный перерыв: по умолчанию 15 минут.
- Предложение длинного перерыва после четырёх завершённых рабочих сессий.
- Настройка длительности каждого режима.
- Старт, пауза и продолжение.
- Сброс таймера и пропуск текущего этапа с подтверждением.
- Круговой индикатор прогресса и оставшееся время.
- Индикатор номера сессии в цикле.
- Звуковой сигнал завершения с возможностью выключить звук.
- Отображение оставшегося времени в заголовке вкладки.

Таймер сверяется с реальным временем. Переключение вкладок не замедляет рабочую сессию. После перезагрузки страницы восстанавливается состояние таймера.

Завершённая рабочая сессия учитывается один раз. Следующий этап ждёт ручного запуска. Пропуск или сброс не добавляют минуты в статистику. Если устройство спало, приложение при возвращении сохраняет одну завершённую сессию, а не несколько вымышленных циклов.

В браузерной первой версии звуковой сигнал при закрытой вкладке или спящем устройстве не гарантируется.

### 2. Простой список задач

- Быстрое добавление задачи.
- Выбор текущей задачи для фокуса.
- Отображение выбранной задачи под таймером.
- Отметка задачи как выполненной.
- Возврат выполненной задачи в работу.
- Удаление отдельной задачи.
- Очистка выполненных задач.
- Счётчик незавершённых задач.

При очистке готовых задач сохраняется дневной счётчик выполненных дел.

Редактирование подробностей, сроки, проекты и повторение относятся к разрабатываемой второй версии.

### 3. Статистика и небольшая цель

- Завершённые минуты фокуса за сегодня.
- Количество завершённых рабочих сессий.
- Количество выполненных за день задач.
- Настраиваемая цель по числу рабочих сессий в день.
- Прогресс достижения цели.
- График минут фокуса за последние семь дней.
- Итоговые показатели за неделю.
- Список последних десяти сессий: задача, дата, время и продолжительность.

Дни определяются по часовому поясу устройства. В статистику фокуса попадают только завершённые рабочие сессии.

### 4. Идеи для перерыва

Отдельная страница с четырьмя простыми вариантами:

- Отвести взгляд от монитора и посмотреть на дальний предмет.
- Если удобно, встать и немного пройтись.
- Сменить положение и убрать руки с клавиатуры.
- На несколько минут переключиться на занятие без экрана.

Есть ссылки на рекомендации OSHA, на которых основаны эти идеи. С этой страницы можно запустить короткий перерыв.

### 5. Интерфейс

- Тёмное оформление с зелёными акцентами.
- Русский и английский языки.
- Адаптация к узким экранам телефонов.
- Режим без отвлечений.
- Управление с клавиатуры.
- Пробел — старт и пауза.
- Клавиши 1, 2 и 3 — переключение основных страниц.
- Escape — выход из режима без отвлечений и закрытие диалогов.
- Подписи элементов для скринридеров, заметный фокус клавиатуры и поддержка уменьшения анимации.

Горячие клавиши не мешают вводу текста. Автоматические проверки доступности проходят для основных страниц и настроек; они не заменяют ручное тестирование людьми.

### 6. Данные и работа без интернета

- Сохранение задач, настроек, таймера и истории в браузере.
- Работа без интернета после первого успешного посещения и кэширования приложения.
- Экспорт резервной копии в JSON.
- Восстановление данных из резервной копии.
- Удаление пользовательских данных с подтверждением.
- Обновление состояния между открытыми вкладками.
- Проверка и ограничение размеров восстанавливаемых данных.

В первой версии данные привязаны к браузеру и адресу приложения. Они не синхронизируются автоматически с другим устройством.

## Вторая версия: устанавливаемое приложение

### Платформы и распространение

Планируемые файлы в GitHub Releases:

| Платформа | Формат | Как пользоваться |
| --- | --- | --- |
| Windows x64 | Установщик .exe | Скачать, установить, запускать через ярлык или меню «Пуск» |
| Windows x64 | Portable .exe | Скачать и запускать без установки |
| Linux x64 | AppImage | Скачать, разрешить выполнение и запустить |
| Android | APK | Скачать на телефон и установить из файла |

iOS в текущую разработку не входит.

**Конечному пользователю не понадобятся Node.js, терминал, Android Studio или запуск локального сервера.** Эти инструменты нужны разработчикам для сборки исходного кода.

Планируется публиковать рядом с файлами установки исходники соответствующей версии, описание изменений и контрольные суммы SHA-256.

### Системные функции ПК

- Отдельное окно приложения.
- Иконка и ярлык для запуска.
- Значок в системном трее.
- Сворачивание в трей с продолжением текущей сессии.
- Открытие приложения и старт/пауза через меню трея.
- Закрепление окна поверх других окон.
- Компактный режим таймера.
- Системное уведомление о завершении этапа.
- Опциональный запуск вместе с Windows.
- Хранение данных в пользовательской папке приложения.
- Экспорт через системное окно сохранения файла.

Код основной оболочки для ПК подготовлен, Setup и файл без установки собраны. Нативный smoke-test остановился из-за ACL текущей среды; перечисленные системные возможности пока не прошли приёмку.

### Системные функции Android

- Отдельное приложение с иконкой в списке приложений.
- Все файлы интерфейса внутри APK: интернет для обычной работы не нужен.
- Хранение состояния в нативных настройках приложения.
- Запланированное локальное уведомление о завершении таймера.
- Запрос разрешения на уведомления по действию пользователя.
- Восстановление таймера после возвращения в приложение.
- Экспорт резервной копии через системное меню «Поделиться».
- Работа системной кнопки «Назад».

Фоновое уведомление зависит от разрешений и ограничений Android. Уведомления во время выключенного телефона или принудительной остановки приложения не обещаются. Точность доставки в энергосберегающем режиме требует отдельной проверки на устройстве.

## Новые пользовательские функции второй версии

### 1. Подробные задачи

- Редактирование названия и параметров задачи.
- Приоритет: высокий, обычный или низкий.
- Срок выполнения.
- Выбор проекта.
- Теги.
- Оценка задачи в количестве фокус-сессий.
- Поиск по названию, проекту и тегам.
- Фильтрация списка по проекту.
- Сортировка с учётом выполнения, приоритета и срока.
- Выделение просроченных задач.

Модель данных, логика и интерфейс этих параметров добавлены. Создание, редактирование, проектный фильтр и поиск по тегам проверены в браузере; нативная приёмка остаётся отдельной задачей.

### 2. Повторяющиеся задачи

- Повтор каждый день.
- Повтор по будням.
- Повтор раз в неделю.
- Создание следующего экземпляра после завершения текущего.
- Защита от дублирования следующего экземпляра.
- Пропуск выходных для задач с повтором по будням.

Повторение должно помогать с регулярными делами: чтением, учёбой, тренировкой навыка или ежедневной подготовкой рабочего места.

### 3. План на день

- Отдельная страница планирования.
- Выбор даты.
- Задачи, назначенные на выбранный день.
- Незавершённые задачи с прошедшим сроком.
- Быстрый переход от задачи к таймеру.
- Заметка на день: что важно сделать или что поможет сосредоточиться.

### 4. Более полезные отчёты

- Распределение времени фокуса по проектам за неделю.
- Привязка рабочей сессии к задаче и проекту.
- Сохранение информации о задаче в истории, даже если она позже удалена из списка.
- Экспорт истории в CSV для таблиц.
- Сохранение существующих дневных и недельных показателей.

### 5. Перенос данных

- Чтение резервных копий первой версии.
- Перенос старых задач и истории в новую модель.
- Нативное хранение на ПК и Android.
- Сохранение экспорта и восстановления JSON.
- Перенос между ПК и телефоном через резервную копию.

Автоматическая синхронизация между устройствами пока не реализована. Решение о включении её в первую устанавливаемую версию ещё не принято: пользователю задан вопрос о необходимости этой функции.

## Дальнейшее развитие

Следующие возможности рассматриваются для последующих выпусков и пока не обещаны в текущей сборке:

- Автоматическая синхронизация между ПК и телефоном.
- Разрешение конфликтов при изменении данных на нескольких устройствах.
- Автоматические обновления настольного приложения.
- Подпись Windows-установщика и постоянный ключ подписи Android-релизов.
- Дополнительные переводы.
- Проверка доступности со скринридерами на реальных устройствах.
- Дополнительные настройки расписания и напоминаний.

Автоматическая синхронизация — отдельная задача: нужно выбрать серверную часть или пользовательское хранилище, способ входа, правила приватности и разрешение конфликтов. Сейчас проект не требует аккаунта и не содержит работающего облачного сервиса.

## Открытый исходный код

Присутствующая в текущих файлах MIT позволяет изучать код, изменять его, собирать приложение самостоятельно и распространять свои версии с соблюдением условий лицензии. Владелец ещё должен подтвердить окончательный лицензионный выбор для публичного выпуска.

В репозитории предполагаются:

- Исходный код общего интерфейса и логики.
- Код оболочки ПК.
- Проект Android.
- Инструкции по локальному запуску и сборке.
- Автоматические тесты.
- GitHub Actions для проверок и сборки релизов.
- История изменений.
- Инструкция для участников проекта.

Готовые программы будут размещаться в **Releases**. Кнопка **Code → Download ZIP** предназначена для скачивания исходников и не заменяет установщик.

## Технологии

- Общий интерфейс: HTML, CSS и JavaScript.
- Сборка интерфейса: Vite.
- Приложение ПК: Electron.
- Установщик Windows: electron-builder и NSIS.
- Приложение Android: Capacitor и нативные плагины.
- Тестирование логики: Node.js Test Runner.
- Проверки интерфейса: Playwright.
- Автоматические проверки доступности: axe.
- Лицензия исходников: MIT.

Текущая локальная разработка идёт во временной папке на C. Окончательное размещение на D и публикация в GitHub остаются отдельными незавершёнными действиями из-за доступа к рабочей папке и авторизации.

## Критерий готовности устанавливаемой версии

Версию можно считать готовой, когда:

1. Все заявленные функции доступны через интерфейс и проходят соответствующие проверки.
2. Установщик Windows собран и приложение действительно запускается.
3. APK собран и проверен на Android-устройстве или эмуляторе.
4. Резервные копии первой версии читаются без потери поддерживаемых данных.
5. Тесты таймера, повторяющихся задач, сохранения и интерфейса проходят.
6. Исходники и соответствующие файлы установки доступны в GitHub Releases.

До выполнения этих пунктов новая версия обозначается как разрабатываемая, а не как готовый опубликованный продукт.
