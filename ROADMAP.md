# План развития Focus Break

Основание: аудит текущей ветки от 27 октября 2026 года, [FEATURES.md](FEATURES.md), [AUDIT.md](AUDIT.md) и ТЗ владельца.

Цель ближайшего цикла — первая стабильная Windows-версия. Android следует за стабилизацией общего формата данных. Календарь, привычки, синхронизация и расширения не должны задерживать этот выпуск.

Существующие Electron, Capacitor, JavaScript и Vite сохраняются. Переписывание стека не планируется.

## Этап 7. Необязательные расширения

- Сначала документировать UUID, версии записей, updatedAt/deletedAt, tombstones и конфликты.
- Затем выбрать один вариант синхронизации: ручной обмен, LAN, сервер пользователя или необязательное облако.
- Основной сценарий всегда работает без выбранного сервиса.
- Внешние календари, обновления и расширения добавлять с понятными правами и ошибками.
- ИИ рассматривать только после проверки обычных локальных алгоритмов и согласования передачи данных.
- Собственный сервер, платные зависимости и обязательный аккаунт сейчас не планируются.

## Оценка трудозатрат

Это предварительная инженерная оценка после аудита, а не обещание непрерывной фоновой работы. Учтено переиспользование текущего интерфейса и стека.

### Windows до первого стабильного выпуска

| Работа | Активные часы |
| --- | ---: |
| Хранение, восстановление, безопасные миграции и удаление | 12–20 |
| Завершение базовой модели задач и регрессия | 6–10 |
| Локальные напоминания и сценарии уведомлений | 4–8 |
| Windows-интеграция, темы, горячие клавиши, компактный режим | 5–8 |
| CI, установка, обновление, Portable и документация | 5–10 |
| Подытог | 32–56 |
| С резервом 25% | **40–70** |

### Android после стабилизации общего слоя

| Работа | Активные часы |
| --- | ---: |
| Окружение, сборка и подпись | 6–10 |
| Хранилище и жизненный цикл приложения | 6–10 |
| Уведомления и permissions | 4–8 |
| Мобильная приёмка и документация | 4–8 |
| Подытог | 20–36 |
| С резервом 25% | **25–45** |

Итого основной стабильный продукт на двух платформах: **65–115 активных часов**, примерно 8–15 полных рабочих дней при 8 часах в день. Календарь, привычки, синхронизация и прочие расширения в эту оценку не входят.

Предположения: доступна обычная Windows для нативной приёмки, Android-устройство или эмулятор, рабочая папка с правами записи и доступ к GitHub после отдельного разрешения. Задержки доступа, подписи, внешних сервисов и согласования не равны часам разработки.

## Следующее конкретное изменение

**Нативная приёмка Windows и воспроизводимая сборка.**

Журнал, безопасный импорт, recovery UI и корзина уже добавлены локально. Дальше — актуальный установщик, проверка закрытия, перезапуска и обновления на обычной Windows, затем управление контрольными копиями и полный CI сборки. Нативные ограничения среды не считать пройденной приёмкой.
