# Фактическое состояние функций

Проверено: 27 октября 2026 года. Ветка: `feature/native-apps`.

Это реестр реализации, а не рекламное описание. Версия `2.0.0` в package.json и имени установщика не означает стабильный публичный релиз.

Обозначения:

- **Проверено в браузере** — выполнен соответствующий сценарий общего интерфейса. Это не подтверждает работу нативных возможностей Windows или Android.
- **Проверена логика** — есть проходящий автоматический тест бизнес-логики.
- **Частично** — есть код или интерфейс, но не закрыты требования и/или проверка.
- **Отсутствует** — реализации не найдено.

## Хранение и приватность

| Возможность | Реальное состояние | Ограничение |
| --- | --- | --- |
| Браузерное хранение | Проверено через localStorage | Привязано к origin и браузеру |
| Windows JSON-хранилище | Файловый адаптер проверен автоматическим тестом на Windows | Очередь, fsync, rename, последняя исправная копия; IPC и жизненный цикл Electron ещё требуют приёмки |
| Android Preferences | Частично | Подключён плагин; устройство / APK не проверены |
| JSON-экспорт и импорт | Проверено в браузере | На Android и через Windows SaveDialog не проверено |
| Миграция формата v1 → v2 | Проверена логика и сохранение исходной копии | Нативное обновление установленной версии ещё не проверено |
| Валидация данных | Проверена логика и отказ импорта в UI | Документ отклоняется целиком; ID проверяются; детали по полям доступны в коде, отдельного UI отчёта нет |
| Целостность и восстановление повреждения | Проверено в браузере и файловом адаптере | CRC32, блокировка автосохранения, явное восстановление; нет нативной приёмки Electron/Android |
| Автоматические резервные копии | Предыдущий исправный снимок и копии перед миграцией / импортом / сбросом | Локальные; нет расписания, внешнего носителя, списка копий и политики очистки |
| SQLite | Не используется | Замена хранилища не согласована |
| Версии отдельных записей / tombstones | Отсутствует | UUID и updatedAt состояния недостаточны для будущей синхронизации |
| Обязательный сервер, регистрация, аналитика | Не обнаружены в основном сценарии | Android allowBackup=true требует отдельного решения о системных резервных копиях |
| Автоматическая синхронизация устройств | Отсутствует | Не блокирует офлайн-работу |

## Проверки и выпуск

- Пройдены 55 тестов логики / хранения и 24 браузерных сценария, включая корзину, выбор и перенос каталога, копии, два окна и отказ записи. Четыре сценария desktop UI используют имитацию preload API.
- Дополнительный аудит UI проверил подробные задачи, поиск по тегу, проектный фильтр, повторение, заметку после перезагрузки и CSV.
- axe не нашёл нарушений в выбранных WCAG AA проверках четырёх основных страниц при 1440 и 390 px. Это не полная сертификация доступности.
- Electron smoke-test остановился до показа рабочего интерфейса: ACL папки сборки несовместим с sandbox дочернего процесса в этой среде. Это ограничение проверки, а не доказательство исправности программы на обычной Windows.
- npm audit: 0 production-уязвимостей, 3 moderate в dev-цепочке Capacitor CLI → xcode → uuid.
- GitHub CI теперь собирает Vite перед браузерными тестами; remote-запуск и нативные пакеты ещё не проверены. Корневые версии package.json и package-lock.json согласованы.
- Публичного GitHub Release нет. Лицензия MIT присутствует в исходниках с предыдущего этапа; окончательный выбор требует решения владельца.
